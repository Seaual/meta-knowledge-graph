# Demo GIF 录制指南

## 推荐工具

- **Windows**: [ScreenToGif](https://www.screentogif.com/) (免费，功能强大)
- **macOS**: Kap 或 GIPHY Capture
- **Linux**: Peek

## 录制内容

需要录制 5 个核心功能的操作流程：

### 1. 上传论文 (3-4秒)
- 打开「论文」页面
- 点击上传按钮
- 选择一个 PDF 文件
- 显示文件上传成功

### 2. 知识图谱交互 (4-5秒)
- 切换到「概念」页面
- 拖拽几个节点
- 滚轮缩放
- 点击一个节点显示详情面板

### 3. 发现研究点 (4-5秒)
- 点击「发现研究点」按钮
- 等待 LLM 分析（可以剪辑掉等待时间）
- 显示生成的研究点列表

### 4. 概念去重 (4-5秒)
- 点击「去重扫描」按钮
- 显示扫描结果和合并建议
- 勾选一个建议并执行合并

### 5. 多格式导出 (2-3秒)
- 点击「导出」下拉菜单
- 展示三种格式选项
- 选择 HTML 格式下载

## 录制建议

- **分辨率**: 1280x720 或 1920x1080
- **帧率**: 15-30 fps
- **时长**: 总计 15-20 秒
- **文件大小**: < 5MB
- **格式**: GIF 或 WebP

## 录制后处理

1. 剪辑掉不必要的等待时间（如 LLM 响应等待）
2. 添加简单的转场效果
3. 可以加速某些操作（如文件上传）
4. 保存为 `docs/demo.gif`

## 示例命令 (使用 ffmpeg)

```bash
# 转换视频为 GIF
ffmpeg -i recording.mp4 -vf "fps=15,scale=1280:-1:flags=lanczos" -c:v gif demo.gif

# 压缩 GIF
gifsicle -O3 --colors 256 demo.gif -o demo-optimized.gif
```
